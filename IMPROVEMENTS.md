# Binance Square Bot 2.0 — изменения

Workflow `.github/workflows/run.yml` не изменён.

## Что исправлено

- Используются только закрытые свечи Binance и Bybit.
- Правильно рассчитываются изменения за 1, 4 и 24 часа с учётом таймфрейма.
- Поддержка, сопротивление и swing-уровни рассчитываются без текущей свечи.
- Исправлены breakout, breakdown, liquidity sweep и false breakout.
- Добавлены отдельные LONG/SHORT pullback и continuation-сигналы.
- Уровни входа, стопа и целей рассчитываются симметрично для LONG и SHORT.
- R/R в фильтре, посте и карточке теперь является реальным отношением до TP3, а не внутренним баллом.
- Удалён опасный fallback: если BTC/funding-фильтры отклонили все сетапы, бот ничего не публикует.
- Confidence заменён на честную «оценку качества сетапа»; она не называется вероятностью прибыли.
- Генератор больше не теряет вход, TP1/TP2/TP3, стоп и CTA.
- Удалены неподтверждённые заявления о китах, гарантированной прибыли и «90% точности».
- AI-полировка по умолчанию выключена. При включении результат проверяется на сохранность всех уровней.
- Добавлена обязательная проверка текста перед публикацией.
- Исправлены цены дешёвых монет, цвета стопа/целей и подписи карточки.
- Улучшена память постов: используется реальная текстовая похожесть вместо сравнения первых 50 символов.
- История и память сохраняются атомарно, чтобы не повреждаться при прерывании процесса.
- Уменьшено количество API-запросов: 15m/1h для общего списка, 4h/1d только для шорт-листа.
- Удалены зависимости `ta` и `mplfinance`; индикаторы и свечной график работают на pandas/numpy/matplotlib.

## Улучшения для охватов

- Несколько вариантов поста генерируются локально, публикуется вариант с лучшей оценкой качества.
- Пост имеет стабильную структуру: факт → контекст → уровни → отмена сценария → вопрос аудитории.
- Используется один содержательный вопрос вместо навязчивых CTA.
- Ограничено число эмодзи и хэштегов.
- Заголовок строится из реально обнаруженного события, а не из случайного кликбейта.
- В изображениях усилена визуальная иерархия: тикер, направление, вход, стоп, цели и R/R читаются сразу.

## Проверка

```bash
pip install -r requirements.txt
python self_test.py
```

Для полного запуска без публикации:

```bash
DRY_RUN=1 python main.py
```

## Основные переменные

- `MIN_SIGNAL_SCORE=54` — минимальный итоговый скор.
- `MIN_RR=1.5` — минимальный реальный R/R.
- `POST_VARIANTS=5` — число вариантов текста.
- `MIN_POST_QUALITY=72` — минимальная оценка поста.
- `STRICT_BTC_FILTER=1` — не публиковать сетап против сильного движения BTC.
- `ENABLE_AI_POLISH=0` — безопасный детерминированный текст без AI-перефразирования.
